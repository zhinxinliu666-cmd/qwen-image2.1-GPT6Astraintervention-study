# 复现范围

## CPU数值复核

运行 `python scripts/summarize_results.py`，无需安装第三方包。脚本读取逐对差值，按来源汇总，输出各指标均值。结果应包含DINO +0.03474011、CLIP L/14风格 −0.00190325及B/32风格 −0.00261945。

## GPU实验记录

`configs/recorded_environment.json`记录历史GPU运行环境。diffusers使用开发版本，原始安装来自main分支归档。该记录用于说明历史环境，不能仅凭版本号保证当前安装获得完全相同实现。

当前公开目录提供统计复核与实验记录。历史GPU脚本已收录于experiments/archive，保留原路径依赖；另提供参数化的原模型/静态权重补丁入口，尚未进行新的GPU复跑。完整核心产物已另行备份并校验，包括原尺寸输出、权重补丁和拟合统计量。
