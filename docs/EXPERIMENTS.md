# 实验路线与发现

## 研究问题

在艺术风格编辑中，局部权重、注意力计算和采样函数干预能否保持对象与布局，同时保留水彩、油画、素描等目标风格？

## 路线

|干预|控制与核验|观察|
|---|---|---|
|Query与空间注意力|生成阶段及参考特征对照|强约束可能削弱风格|
|注意力头输出投影权重|选定位置与随机对照，恢复原权重|未获得可靠增益|
|FlowEdit/SDEdit类移植与反演|固定开发来源，内容和风格联合评价|部分设置提升内容分数，但压制艺术转换|
|频率约束与补偿|CFG消融、低频对照、固定候选新来源验证|内容代理指标改善得到复现，存在风格和计算成本代价|
|输出层蒸馏|4来源三风格轨迹，三强度学习补丁与随机补丁|未取得可靠改善|
|仅早期启用权重补丁|前12步启用，后续恢复|时段限制未解决上述失败|

## 统计设计

12来源确认集包含三种风格和两个种子，72对输出。另30来源扩展包含三种风格与一个种子，90对输出。先在来源内平均再跨来源统计，避免把同一来源的风格版本作为独立来源。扩展集29/30来源的平均DINO差值为正。

冻结候选的频率修正只作用前12步，采用db4小波两级分解、alpha1、gamma1.6、每4步补偿、前2步跳过补偿。40步推理，CFG1.2，1024输出分辨率，BF16，关闭KV缓存。约80次模型前向，原模型40次。

## 机制线索

彩色DINO两种子平均差值+0.03302，转灰度后+0.03211，再统一亮度统计后+0.03224。该事后检查提示收益不能简单归因于色彩接近，仍需分离纹理和结构因素。灰度输入偏离常规评估分布。

## 视觉证据范围

12来源第二种子36对助手隐藏标签审查为4对内容偏好候选、32对平局，风格36对平局。来源先前已见过，整体指标在审查途中可见。30新来源完整90对视觉判断待补齐。seed42曾有一次拼图边界误判，后经原文件检查撤回，该例不计为模型失效。

对象新增的行人/伞和货车为预选恒等编辑案例。频率干预修复前者，货车仍存在。此结果不用于估计总体错误率。模型的具体内部致错机制尚待进一步研究。
